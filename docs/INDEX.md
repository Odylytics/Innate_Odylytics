```
  experiments/                    code (E1–E27, training, team data analysis, dry-run)
  results/                        generated result tables (.md/.txt)
  models/                         fake-data models, reference only

  data/, external/                third-party data and code: GIT-IGNORED, not submitted
tools/                            builds the submission package: build_submission.sh, build_pptx.js (editable slides), product-guide.html, assets, fonts

  contest/  plan/  research/  submission/  brand/  (research/notes/ = paper reading notes by group; brand/ = Innate brand kit + asset pack)

```
Downloaded data (git-ignored): `research/data/` (extracted) and the original zips in `research/data/_archives/` (Touchalytics, Aalto).

## Conventions
- Experiment ids: E1–E14 as in `ai-research.md` (E14 = the new digit-string flow, done by the web team); E18–E28 added 25–26/11. **E15–E17 are unused** (renamed to E19–E21 to avoid a clash with E14).
- Every number in the documents is produced by code in `research/experiments/`; none is edited by hand. Numbers on fake data are only for trying the pipeline and do not go on slides.
- User data: only timing, coordinates, event type, character count; the PIN content, the amount, and typed content are not stored.
