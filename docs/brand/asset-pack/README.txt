INNATE — BRAND ASSET PACK
=========================
Source: Figma file "Innate", page "Logo" (refined Continuous Gesture master + Brand identity kit).
Every logo is supplied as SVG (scalable, use for web/print) and PNG (transparent background).

FOLDERS
01 Logo - Horizontal   Primary logo: "in" symbol + "innate" wordmark. Default choice.
02 Logo - Stacked      Symbol above wordmark. Square / centred layouts.
03 Symbol mark         The "in" gesture on its own. Avatars, stamps, small spaces.
04 Wordmark            "innate" on its own. Only when the symbol appears nearby.
05 App icon            1024 px. "square" = full-bleed for App Store / Play upload
                       (the store applies its own corner mask); "rounded" = previews, decks.
06 Favicon             favicon.ico (16/32/48), favicon.svg, PNG sizes, apple-touch-icon, android-chrome.
07 Colour palette      Palette sheet PNG + CSS variables + text list (HEX / RGB / use).
08 Backgrounds         Ink + cropped gesture background (from the website hero), 1080p, 4K and
                       portrait 1080x1920; light Cloud version; Reference/ = full hero mockup.

COLOUR VERSIONS (file suffix)
fullcolor    Innate Ink + Living Jade dot       -> light backgrounds (white, Cloud, Mint Mist)
reversed     White + Pulse Mint dot             -> dark backgrounds (Ink, Deep Teal)
mono-ink     Innate Ink only                    -> one-colour print on light
mono-white   White only                         -> one-colour on dark / on Living Jade
mono-jade    Living Jade only                   -> on Innate Ink
mono-black   Pure black #000000                 -> fax, newspaper, laser engraving

RULES
- Clear space on all sides = the width inside the "n" (about 27% of the symbol height).
- Minimum size: symbol 16 px / 5 mm; horizontal logo 20 px symbol height / 6 mm.
- Never stretch, rotate, recolour, add effects or gradients, or retype "innate" in a font.
